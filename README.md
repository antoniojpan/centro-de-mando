# Centro de Mando

Página web de prueba del repositorio **Centro de Mando**.

## Ver la página

Una vez subido el código a GitHub, activa **GitHub Pages**:

1. Ve a tu repositorio en GitHub → **Settings** → **Pages**.
2. En **Build and deployment** → **Source**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda. La página estará disponible en: `https://TU_USUARIO.github.io/centro-de-mando/`

## Estructura

```
centro-de-mando/
├── index.html   # Página principal
└── README.md    # Este archivo
```

## Despliegue local

Abre `index.html` directamente en tu navegador.
